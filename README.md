# 小医生助手 · 问诊流水线

把「专家 + 技能 + 连接器」串成一条线的中文问诊工作流，用于 WorkBuddy。说一句"启动问诊流水线 + 症状/照片"，即按固定顺序编排：**安全门 → 微医初筛 → 多轮追问 → 循证溯源 → 结构化摘要 → 投递**。

> ⚠️ 本项目仅为辅助参考工具，**不能替代医生诊断**。所有医学结论由下游专业能力与连接器产出，编排器只做调度与格式化。

---

## 一、包里有什么

| 文件 | 说明 |
|---|---|
| `skills/小医生助手问诊流水线/SKILL.md` | 工作流总控 v3.0（编排器） |
| `skills/多轮问诊追问/SKILL.md` | 多轮结构化追问技能 v2.0（Doctor-R1 式，5 轮提问 + 1 轮收尾） |

这两个是**自建技能**，直接复制安装即可。其余能力依赖外部专家/技能/连接器（见第三节），需在新电脑上另行准备。

---

## 二、安装步骤（家里电脑）

### 1. 安装两个自建技能

找到新电脑的 WorkBuddy **用户级技能目录**（默认 `~/.workbuddy/skills/`，Windows 为 `C:\Users\<你的用户名>\.workbuddy\skills\`）：

- 把本包的 `skills/小医生助手问诊流水线/` 整个文件夹复制进去；
- 把 `skills/多轮问诊追问/` 整个文件夹复制进去。

最终目录结构应为：

```
~/.workbuddy/skills/
├── 小医生助手问诊流水线/
│   └── SKILL.md      ← 根目录第一层就能看到
└── 多轮问诊追问/
    └── SKILL.md      ← 根目录第一层就能看到
```

> ⚠️ 常见坑：SKILL.md 必须在文件夹根目录。如果从 ZIP 解压后多套了一层（如 `.../xiao-doctor-consultation-pipeline/skills/小医生助手问诊流水线/`），只复制含 SKILL.md 的**最内层文件夹**，不要整包塞进 skills 目录。

### 2. 准备外部依赖（见第三节）

### 3. 重启 WorkBuddy

新技能需重启 WorkBuddy 才会出现在"已安装"列表并生效。

### 4. 验证

新开一个对话（**不要选中「微小医」专家**，否则它会抢走路由），输入：

```
启动问诊流水线：我最近三天右边太阳穴一阵一阵地跳着疼
```

应看到：第 0 步安全门提示 → 微医初筛结果 → 每轮只问一个维度的追问。

## 三、外部依赖清单（新电脑需要另行准备）

| 依赖 | 类型 | 作用 | 缺失时的影响 / 替代 |
|---|---|---|---|
| **微医健康管理专家**（we-health-expert） | 官方专家 | 第 1 步初筛、用药咨询、报告解读、医院推荐；**所有医学结论的主体来源** | 🔴 核心依赖。在 WorkBuddy「专家」市场搜索"微医/微小医"安装并激活。缺失时工作流无法产出医学结论 |
| **医渡智循**（yidu-evidence） | 技能 | 第 3 步循证溯源（带文献引用） | 🟡 可选。四级降级链的第 1 级，缺失则跳到第 2/3 级 |
| **medical-guidelines-suite** | 技能 | 第 3 步指南 RAG（NCCN/ESMO/CSCO） | 🟡 可选。需 Python 依赖（docling/openpyxl/qmd）；缺失可跳过 |
| **agent-mail** | 连接器 | 第 5 步投递到邮箱 | 🟡 可选。缺失则不提供邮箱投递 |
| **tencent-docs** | 连接器 | 第 5 步存腾讯文档 | 🟡 可选。企业版存储满会自动降级 WorkBuddy 资料库 / 金山文档 kdocs |

> 最小可跑配置：只装「微医健康管理专家」+ 这两个自建技能，即可跑通安全门→初筛→追问→摘要主流程；循证与投递是锦上添花。

## 四、使用方法

**咒语**：`启动问诊流水线` + 症状描述 / 照片

- 每次只回答一个问题，像回答医生问诊一样；
- 问全后自动出摘要：一句话结论 + 关键信息 + 证据参考 + 就医建议（科室+紧急程度）+ 免责声明；
- 最后询问是否投递到邮箱/文档，**确认后才外发**。

**触发词**（不必每次都念咒语）：启动问诊流水线、问诊流水线、帮我看看症状、体检报告解读、这药能不能吃。

## 五、已知问题与处置（本机实测，2026-11-18）

| 问题 | 现象 | 处置 |
|---|---|---|
| 🔴 专家抢占路由 | 「微小医」专家 active 时，健康问题被它直连 API 截走，工作流不生效 | 用工作流前**取消选中微小医专家**，或新开对话不选专家 |
| 🟡 医渡 429 | 医渡智循返回 `code=429 请不要重复请求`（HTTP 200，服务端拦截） | 不重试、不改内容重发；按四级降级链走指南RAG / 微医用药咨询；严禁编造引用 |
| 🟡 腾讯文档满容 | 企业版创建文件报 `400013 存储空间已满` | 自动降级 WorkBuddy 资料库（HTML→import_html→publish_page），再兜底金山文档 |
| 🟢 6 维度表述 | 教程说"6 维度"，实为 5 轮提问 + 1 轮收尾总结 | 已对齐，无维度数矛盾 |
